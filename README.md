# NM Calçados — Protótipo visual de e-commerce

Protótipo front-end independente em HTML, CSS e JavaScript puro.

## Páginas
- `index.html` — home completa
- `loja.html` — catálogo com filtros e ordenação
- `produto.html` — página de produto
- `checkout.html` — checkout visual

## Recursos já simulados
- Busca
- Carrinho lateral com `localStorage`
- Filtros de categoria, tamanho, preço e estoque
- Ordenação
- Favoritos visuais
- Produto com escolha de tamanho
- Checkout visual
- Integração visual com WhatsApp
- Layout responsivo

## Importante
Ainda não existe backend, banco de dados, estoque real, autenticação, gateway de pagamento, cálculo de frete ou painel administrativo. As imagens são demonstrativas e carregadas de URLs externas.

Para visualizar, basta abrir `index.html` em um navegador. Para uma experiência melhor, use um servidor local simples, como a extensão Live Server do VS Code.
